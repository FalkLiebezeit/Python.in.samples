# Algorithmen in Python
Dieses Verzeichnis enthält den Quellcode, der zum Buch *Algorithmen in Python* (Originaltitel *Classic Computer Science Problems in Python*) von David Kopec gehört. Sie finden die Quellcodes nach Kapiteln organisiert vor. **Während Sie das Buch lesen, enthält jedes Codelistung einen Dateinamen, der einer Datei in diesem Verzeichnis entspricht.**

## Versionen und Packages
Der Quellcode in diesem Verzeichnis benötigt Python 3.7 sowie die Instalation des Packages [typing_extensions](https://github.com/python/typing/tree/master/typing_extensions). Aufgrund seiner ausgiebigen Verwendung von Python-3.7-Features (Datenklassen, erweiterte Type-Hints usw.) funktioniert ein Großteil des Quellcodes nicht mit früheren Versionen von Python. Sie können das Package `typing_extensions` mit `pip3 install typing_extensions` oder `pip install typing_extensions` installieren, je nach Ihrer Python/pip-Installation.

## Andere Bücher und Sprachen
Dies ist das zweite Buch in der bei Manning erscheinenden Reihe Classic Computer Science Problems von David Kopec. Es versucht, klassische Informatikaufgaben nach Python-Art zu lehren. Vielleicht möchten Sie sich auch das erste Buch in der Reihe, *Classic Computer Science Problems in Swift*, anschauen; es behandelt praktisch dieselben Aufgaben im Swift-Stil. Sie finden das Repository für das andere Buch auf [GitHub](https://github.com/davecom/ClassicComputerScienceProblemsInSwift). Ein Leser hat zudem die ersten fünf Kapitel des Buches [in C++](https://github.com/araya-andres/classic_computer_sci) reimplementiert, und der Übersetzer dieses Buches arbeitet an einer [PHP-Portierung](https://github.com/SaschaKersken/ClassicComputerScienceProblemsInPhp).
