# Building

Visual Studio Code runs on all major desktop platforms, making it super versatile for developers. Here's a quick breakdown:

🪟 **Windows**  
- Windows 10 and 11 (64-bit)

🍎 **macOS**  
- Supported on the latest release and the two previous versions that still receive Apple security updates

🐧 **Linux**  
- **Debian-based**: Ubuntu Desktop 20.04, Debian 10  
- **Red Hat-based**: Red Hat Enterprise Linux 8, Fedora 36

💡 Note: While VS Code itself doesn’t support running fully inside containers or virtualized environments like App-V or MSIX, it *does* support development inside containers using the **Dev Containers extension**.
